Linux-Dateiberechtigungen (rwx, chmod, chown) AP1 AP2

Einstieg

Wer welche Datei öffnen, hineinschauen oder verändern darf, regelt unter Linux ein Dreier-Schlüsselsystem: ein Schlüssel für den Eigentümer, ein gemeinsamer Team-Schlüssel für die Gruppe, und ein allgemeiner Schlüssel für alle anderen — drei feste Schlüsselarten statt einer Gästeliste mit Namen.

Konzept

Das rwx-Rechtesystem

Jede Datei und jedes Verzeichnis hat drei Rechte für drei Gruppen — kurz „ugo“ genannt:

Rechtbei Dateienbei Verzeichnissen
r (read)Inhalt lesenInhalt auflisten (ls)
w (write)Inhalt ändernDateien erstellen/löschen
x (execute)als Programm ausführenVerzeichnis betreten (cd)
Gruppe (u/g/o)Bedeutung
u — User/Ownerder Eigentümer der Datei (Ersteller wird automatisch Eigentümer)
g — Groupeine Benutzergruppe, alle Mitglieder teilen sich diese Rechte
o — Othersalle übrigen Benutzer des Systems

Mit ls -l werden die Rechte angezeigt, z. B. -rwxr-xr--: Owner darf alles (rwx), Gruppe darf lesen und ausführen (r-x), alle anderen dürfen nur lesen (r--).

Oktalnotation und chmod

RechtWert
r (read)4
w (write)2
x (execute)1

Die Werte einer Gruppe werden addiert: rwx = 7 (4+2+1), rw- = 6 (4+2), r-x = 5 (4+1). Drei Ziffern hintereinander (Owner-Group-Others) ergeben die Oktalnotation für chmod:

BefehlBedeutung
chmod 755 skript.shrwxr-xr-x — Owner alles, Gruppe/Andere lesen+ausführen
chmod 644 datei.txtrw-r--r-- — Owner lesen+schreiben, Rest nur lesen
chmod 600 privat.keyrw------- — nur Owner darf lesen/schreiben
chmod 777 datei.txtrwxrwxrwx — alle dürfen alles (fast immer ein Sicherheitsrisiko!)

Mit chown ben:users datei.txt wird der Eigentümer auf „ben“ und die Gruppe auf „users“ gesetzt. Die Option -R (z. B. chmod -R 755 /var/www/) wendet eine Änderung rekursiv auf einen ganzen Ordner samt Inhalt an.

Windows kennt ein deutlich feineres, aber auch komplexeres Berechtigungsmodell (ACL mit einzelnen Einträgen pro Benutzer statt nur drei festen Gruppen) — siehe Einheit „Windows-Berechtigungen (ACL)“.

Praxisbeispiel

Ein Techniker der TechNord GmbH konfiguriert die Rechte auf einem Linux-Webserver:

  • Deploy-Skript ausführbar machen: chmod 755 deploy.sh — Owner darf alles, alle anderen nur lesen und ausführen.
  • Web-Verzeichnis dem Webserver-Prozess übergeben: chown www-data:www-data /var/www/technord, damit der Webserver-Dienst korrekt darauf zugreifen kann.
  • Privaten Schlüssel absichern: chmod 600 id_rsa — nur der Owner darf die Datei lesen oder ändern, ein SSH-Schlüssel mit offeneren Rechten wird von vielen Systemen sogar aus Sicherheitsgründen abgelehnt.
  • Rekursiv auf einen ganzen Ordner anwenden: chmod -R 755 /var/www/technord, damit alle Unterdateien einheitliche Rechte erhalten.

Merksatz

Rechte gelten für Owner/Group/Others (ugo) je r/w/x — Oktalwerte r=4, w=2, x=1 addiert ergeben Werte wie 755, 644, 600. chmod ändert die Rechte, chmod 777 ist fast immer ein Sicherheitsrisiko. chown ändert Eigentümer und Gruppe, -R wendet eine Änderung rekursiv auf einen ganzen Ordner an.
