Du hast den Schutzbedarf der Anwendungen bestimmt. Aber Maßnahmen setzt du an Geräten, Räumen und Leitungen um. Also musst du den Schutzbedarf von den Anwendungen auf die Technik übertragen. Dafür gibt es drei Regeln.

Maximumprinzip: Das Wichtigste zählt

Laufen auf einem IT-System mehrere Anwendungen, bekommt das System je Schutzziel den höchsten Schutzbedarf der Anwendungen, die darauf laufen. Das ist das Maximumprinzip. Ein Server mit einer Anwendung „sehr hoch“ und fünf Anwendungen „normal“ ist bei diesem Schutzziel „sehr hoch“, denn ein Angriff auf den Server trifft auch die wichtigste Anwendung.

Genauso erbt ein Raum den Schutzbedarf der Systeme, die darin stehen, und eine Verbindung den Schutzbedarf der Daten, die über sie laufen.

Kumulationseffekt: Viele Kleine ergeben etwas Großes

Manchmal ist das Ganze schlimmer als jeder Teil. Laufen auf einem Server viele Anwendungen mit normalem Verfügbarkeitsbedarf, legt sein Ausfall alle gleichzeitig lahm. Der Gesamtschaden kann dann beträchtlich sein. Der Server bekommt in diesem Fall einen höheren Schutzbedarf als jede einzelne Anwendung. Das nennt man Kumulationseffekt.

Verteilungseffekt: Redundanz entlastet

Umgekehrt kann eine Anwendung mit hohem Verfügbarkeitsbedarf auf mehrere Systeme verteilt sein, etwa auf zwei Server, die sich gegenseitig vertreten. Fällt einer aus, übernimmt der andere. Für das einzelne System genügt dann ein niedrigerer Schutzbedarf bei der Verfügbarkeit. Das ist der Verteilungseffekt. Er betrifft vor allem die Verfügbarkeit: Vertrauliche Daten bleiben vertraulich, egal auf wie vielen Servern sie liegen.

Beispiel

Ein Architekturbüro hat ein NAS, auf dem Projektpläne (Verfügbarkeit normal), Rechnungen (normal), Angebote (normal) und die Zeiterfassung (normal) liegen. Einzeln ist jeder Ausfall verkraftbar. Fällt aber das NAS aus, steht das ganze Büro still, kurz vor einer Abgabefrist. Wegen des Kumulationseffekts stuft das Büro die Verfügbarkeit des NAS als „hoch“ ein.

Der Durchschnitt zählt nicht. Bei einem System mit „sehr hoch“, „normal“ und „normal“ ist das Ergebnis nicht „hoch“, sondern nach dem Maximumprinzip „sehr hoch“.

  • Maximumprinzip: ein System erbt den höchsten Schutzbedarf seiner Anwendungen.
  • Kumulationseffekt: viele Anwendungen können ihn erhöhen.
  • Verteilungseffekt: Redundanz kann ihn bei der Verfügbarkeit senken.
