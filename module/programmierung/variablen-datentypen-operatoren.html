Variablen, Datentypen & Operatoren AP1

Einstieg

Eine Variable ist wie eine beschriftete Kiste, in der über die Zeit unterschiedlicher Inhalt liegen kann — solange er zur angegebenen Kistenart passt: eine Kiste für Zahlen, eine für Text, eine für Ja/Nein-Werte. Operatoren sind die Werkzeuge, mit denen mit dem Kisteninhalt gearbeitet wird: rechnen (Taschenrechner), vergleichen (Waage: größer, kleiner, gleich) oder mehrere Bedingungen verknüpfen (UND/ODER, wie „nur wenn beides zutrifft“ oder „wenn mindestens eines zutrifft“).

Konzept

Variablen und Datentypen

Eine Variable ist ein benannter Speicherplatz für einen Wert, der sich während der Programmlaufzeit ändern kann. Der Datentyp legt fest, welche Art von Wert gespeichert werden darf:

DatentypBeispielwert
Ganzzahl (Integer)42
Gleitkommazahl (Float/Double)3.14
Zeichenkette (String)"Hallo Welt"
Wahrheitswert (Boolean)true / false

Arithmetische Operatoren

Rechnen mit Zahlen (Integer/Float):

OperatorBedeutungBeispiel
+Addition5 + 3 → 8
-Subtraktion5 - 3 → 2
*Multiplikation5 * 3 → 15
/Division7 / 2 → 3.5
MODRest der Ganzzahldivision7 MOD 2 → 1

Vergleichsoperatoren

Vergleichen zweier Werte, das Ergebnis ist immer ein Boolean (wahr oder falsch):

OperatorBedeutungBeispiel
==gleich5 == 5 → wahr
!=ungleich5 != 3 → wahr
< / >kleiner / größer3 < 5 → wahr
<= / >=kleiner-gleich / größer-gleich5 >= 5 → wahr

Logische Operatoren

Verknüpfen mehrerer Bedingungen (Boolean-Werte) zu einer neuen Bedingung:

OperatorBedeutung
UNDwahr nur, wenn beide Teilbedingungen wahr sind
ODERwahr, wenn mindestens eine Teilbedingung wahr ist
NICHTkehrt eine Bedingung um (aus wahr wird falsch und umgekehrt)

Praxisbeispiel

Die TechNord GmbH prüft, ob ein Kunde Anspruch auf einen Premium-Rabatt hat: mindestens 100 Stück bestellt und Premium-Status.

Menge = 120 IstPremium = true Einzelpreis = 19.99 Rabattsatz = 0.10 Anspruch = (Menge >= 100) UND (IstPremium == true) Rabattbetrag = Menge * Einzelpreis * Rabattsatz

Menge >= 100 und IstPremium == true sind zwei Vergleiche, jeder liefert für sich einen Boolean. Der UND-Operator verknüpft beide: Anspruch wird nur dann true, wenn beide Teilbedingungen zutreffen. Rabattbetrag wird über die arithmetischen Operatoren * (Multiplikation) aus Menge, Einzelpreis und Rabattsatz berechnet.

Übungsaufgabe

Ein Azubi soll den Bruttolohn aus Stundenlohn und geleisteten Stunden berechnen und danach prüfen, ob Überstunden (mehr als 40 Stunden) angefallen sind. Schreibe die Berechnung in Pseudocode.

Musterlösung anzeigen 
Stundenlohn = 18.50
Stunden = 43

Bruttolohn = Stundenlohn * Stunden
Ueberstunden = Stunden > 40

Bruttolohn entsteht über den arithmetischen Operator * (Multiplikation). Ueberstunden entsteht über den Vergleichsoperator > und liefert direkt einen Boolean (hier: true, da 43 > 40).

Merksatz

Variable = benannter, veränderlicher Speicherplatz; Datentyp legt die erlaubte Art des Werts fest (Integer, Float, String, Boolean). Arithmetische Operatoren (+, -, *, /, MOD) rechnen mit Werten. Vergleichsoperatoren (==, !=, <, >, <=, >=) liefern immer einen Boolean. Logische Operatoren (UND, ODER, NICHT) verknüpfen mehrere Bedingungen zu einer neuen.
