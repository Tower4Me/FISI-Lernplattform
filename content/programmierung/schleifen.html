Einstieg

Eine Schleife ist wie eine Waschmaschine: „Schleudere, solange noch Wasser im Bottich ist“ (Bedingung wird vor jedem Durchlauf geprüft) oder „schleudere mindestens einmal, prüfe danach, ob noch Wasser da ist“ (Bedingung wird nach dem Durchlauf geprüft). Ohne Schleife müsste jeder einzelne Waschgang von Hand einprogrammiert werden.

Konzept

Eine Schleife wiederholt einen Anweisungsblock, solange bzw. bis eine Bedingung erfüllt ist — ohne dass der Code dafür mehrfach geschrieben werden muss.

Zählschleife

Wird eingesetzt, wenn die Anzahl der Durchläufe im Voraus bekannt ist — entweder als feste Zahl oder als Anzahl der Elemente einer Liste:

FÜR i VON 1 BIS 5 TUE AUSGABE i ENDE FÜR FÜR JEDE Position IN Bestellliste TUE AUSGABE Position ENDE FÜR

Zählschleife mit Index über ein Array

Ein Array (Datenfeld) speichert mehrere Werte desselben Typs unter einem gemeinsamen Namen, durchnummeriert ab Index 0. Reicht FÜR JEDE nicht aus — etwa weil der Index selbst gebraucht wird oder ein Wert an einer bestimmten Position verändert werden soll —, läuft die Zählschleife stattdessen explizit über den Index:

FÜR i VON 0 BIS Länge(Werte) - 1 TUE AUSGABE Werte[i] ENDE FÜR

Werte[i] greift auf das Element an Position i zu. Der Index läuft bis Länge(Werte) - 1, da die Zählung bei 0 beginnt — ein Array mit 5 Elementen hat also die gültigen Indizes 0 bis 4.

Kopfgesteuerte Schleife (SOLANGE)

Prüft die Bedingung vor jedem Durchlauf. Trifft sie von Anfang an nicht zu, läuft die Schleife kein einziges Mal:

SOLANGE Lagerbestand > 0 TUE Lagerbestand = Lagerbestand - 1 ENDE SOLANGE

Fußgesteuerte Schleife (WIEDERHOLE … BIS)

Prüft die Bedingung nach dem Durchlauf und läuft deshalb immer mindestens einmal, selbst wenn die Bedingung von Anfang an zutrifft:

WIEDERHOLE Eingabe = LiesPasswortEingabe() BIS Eingabe korrekt ist

Endlosschleifen vermeiden

Bei jeder Schleife muss sich innerhalb des Schleifenkörpers etwas ändern, das irgendwann die Abbruchbedingung erfüllt (z. B. eine Zählvariable erhöhen oder den Lagerbestand verringern). Fehlt diese Änderung, läuft die Schleife unkontrolliert endlos weiter.

Praxisbeispiel

Auch Schleifen werden oft zunächst in Pseudocode geplant, bevor sie in eine konkrete Sprache übersetzt werden. Ein Raketenstart-Countdown zählt rückwärts — zunächst als Pseudocode-Vorgabe:

FÜR i VON 10 ABWÄRTS BIS 1 TUE AUSGABE i ENDE FÜR AUSGABE "Start!"

Dieselbe Logik in Python (for statt FÜR):

for i in range(10, 0, -1): print(i) print("Start!")

FÜR i VON 10 ABWÄRTS BIS 1 entspricht range(10, 0, -1) — zählt von 10 abwärts bis einschließlich 1 (Schrittweite -1). AUSGABE wird zu print().

Übungsaufgabe

Schreibe eine Schleife in Python, die die Summe der Zahlen von 1 bis 10 berechnet.

Musterlösung anzeigen 
summe = 0
for i in range(1, 11):
    summe = summe + i
print(summe)

Eine Zählschleife passt hier, da die Anzahl der Durchläufe (10) von vornherein feststeht. Bei jedem Durchlauf wird der aktuelle Wert von i zur laufenden summe addiert.

Merksatz

Zählschleife (FÜR): Anzahl der Durchläufe steht vorher fest. Kopfgesteuerte Schleife (SOLANGE): Bedingung wird vorher geprüft, kann null Mal laufen. Fußgesteuerte Schleife (WIEDERHOLE … BIS): Bedingung wird nachher geprüft, läuft mindestens einmal. Jede Schleife braucht eine Änderung im Schleifenkörper, die die Abbruchbedingung irgendwann erfüllt — sonst Endlosschleife.
