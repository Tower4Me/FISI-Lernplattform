Verzweigungen (WENN/SONST) AP1

Einstieg

Eine Verzweigung ist wie ein Verkehrsschild auf einer Reise: „Ist die Straße gesperrt, nimm die Umleitung — sonst fahr geradeaus weiter.“ Ohne dieses Schild würde jedes Programm immer stur denselben Weg nehmen, egal was gerade zutrifft.

Konzept

Eine Verzweigung lässt ein Programm abhängig von einer Bedingung einen von mehreren möglichen Pfaden ausführen. Sie grenzt sich damit von der Sequenz ab, dem Normalfall: Anweisungen werden dort einfach nacheinander abgearbeitet, ohne Auswahl.

Einseitige Verzweigung

Nur ein Pfad ist optional — trifft die Bedingung nicht zu, passiert einfach nichts:

WENN Lagerbestand < 10 DANN Nachbestellung = true ENDE WENN

Zweiseitige Verzweigung

Genau einer von zwei Pfaden wird immer ausgeführt — entweder der DANN-Zweig oder der SONST-Zweig:

WENN Menge >= 100 DANN Rabatt = 10% SONST Rabatt = 0% ENDE WENN

Mehrfache Verzweigung

Mehr als zwei mögliche Pfade werden über SONST WENN-Ketten geprüft. Jede weitere Bedingung wird nur dann geprüft, wenn keine der vorherigen zutraf:

ALGORITHMUS GrößteZahl(a, b, c) WENN a >= b UND a >= c DANN ERGEBNIS = a SONST WENN b >= c DANN ERGEBNIS = b SONST ERGEBNIS = c ENDE WENN RÜCKGABE ERGEBNIS

Eine solche Kette mehrerer SONST WENN auf derselben Ebene wird auch kaskadierte Verzweigung genannt — mehr dazu inklusive Abgrenzung zur Verschachtelung in der Einheit „Verschachtelung & Kaskadierung von Kontrollstrukturen“.

Praxisbeispiel

Ein Auszubildender der TechNord GmbH prüft für eine einzelne Bestellposition, ob Mengenrabatt gilt:

WENN Position.Menge >= 100 DANN Position.Rabatt = 10% SONST Position.Rabatt = 0% ENDE WENN

Die WENN-Verzweigung entscheidet über den Rabattsatz dieser einen Position. Sollen alle Positionen einer ganzen Bestellliste geprüft werden, braucht es zusätzlich eine Schleife um diese Verzweigung herum — dazu mehr in der Einheit „Schleifen“.

Merksatz

Verzweigung = abhängig von einer Bedingung wird einer von mehreren möglichen Pfaden ausgeführt. Einseitig (WENN … DANN, ohne Alternative), zweiseitig (WENN … DANN … SONST, genau ein Pfad) oder mehrfach als Kette aus SONST-WENN (kaskadiert, jede Bedingung nur geprüft, wenn die vorherige nicht zutraf).
