Linux-Konsole AP1 AP2

Einstieg

Die Kommandozeile ist wie ein Gespräch mit dem Betriebssystem in einer sehr kompakten Sprache: statt durch Menüs zu klicken, tippt man kurze Befehlswörter — wer den Wortschatz kennt, kommt oft schneller ans Ziel als mit der Maus, vor allem bei wiederkehrenden Aufgaben auf einem Server. Windows organisiert Laufwerke dabei wie separate Aktenschränke (C:, D:, E:) nebeneinander; Linux kennt nur einen einzigen, riesigen Aktenschrank mit einer festen Schublade an der Wurzel — jeder weitere Datenträger wird als zusätzliche Schublade an einer bestimmten Stelle in diesen einen Schrank eingeschoben (Mounting).

Konzept

Navigation

BefehlZweck
pwdzeigt das aktuelle Arbeitsverzeichnis an (print working directory)
cd Ordnerwechselt in ein Verzeichnis; cd .. wechselt eine Ebene nach oben
ls / ls -llistet den Verzeichnisinhalt bzw. mit Details/Rechten auf

Dateioperationen

BefehlZweck
cp quelle zielkopiert eine Datei
mv quelle zielverschiebt oder benennt eine Datei um
rm dateilöscht eine Datei (unwiderruflich, kein Papierkorb)
mkdir ordnerlegt ein neues Verzeichnis an

Dateiinhalt ansehen und durchsuchen

BefehlZweck
cat dateigibt den kompletten Dateiinhalt aus
less dateizeigt den Inhalt seitenweise an, durchsuchbar, ohne alles auf einmal auszugeben
grep "muster" dateidurchsucht eine Datei zeilenweise nach einem Textmuster — z. B. Fehlermeldungen in Logdateien finden

Befehle lassen sich über die Pipe (|) verketten: Die Ausgabe des einen Befehls wird zur Eingabe des nächsten. Beispiel: cat zugriff.log | grep "error" gibt nur die Zeilen von zugriff.log aus, die „error“ enthalten. Mit > wird eine Ausgabe stattdessen in eine Datei umgeleitet (überschreibt sie), mit >> an eine bestehende Datei angehängt.

Verzeichnisbaum und Mounting

Linux kennt keine Laufwerksbuchstaben wie C: oder D:. Stattdessen gibt es einen einzigen Verzeichnisbaum, beginnend bei der Wurzel /. Jeder weitere Datenträger wird einem Verzeichnis in diesem Baum zugewiesen — diesen Vorgang nennt man Mounting (Einhängen), das Zielverzeichnis heißt Mountpoint (z. B. /mnt/usb). Erst ab dem Moment des Mountens ist der Inhalt des Datenträgers über diesen Pfad erreichbar; nach dem Aushängen (umount) bleibt der Mountpoint selbst bestehen, nur sein Inhalt ist wieder unerreichbar.

Die Datei /etc/fstab (File System Table) steuert, welche Dateisysteme beim Systemstart automatisch gemountet werden:

GerätMountpointTypOptionen
/dev/sda1/ext4defaults
UUID=1A2B-3C4D/mnt/usbvfatauto,user

Eine fehlerhafte /etc/fstab kann dazu führen, dass Linux beim Booten hängenbleibt — deshalb vor jeder Änderung ein Backup anlegen und mit mount -a testen (versucht alle fstab-Einträge zu mounten, ohne neu zu starten).

Hilfe zu Befehlen

man befehl (Manual) zeigt die vollständige Dokumentation eines Befehls mit allen Optionen an — der erste Anlaufpunkt bei einem unbekannten oder vergessenen Parameter. Die Rechte für Dateien und Verzeichnisse (rwx, chmod, chown) sind ein eigenständiges Thema und werden in der Einheit „Linux-Dateiberechtigungen“ behandelt.

Praxisbeispiel

Ein Techniker der TechNord GmbH richtet einen neuen Linux- Webserver ein:

  • Verzeichnis wechseln und Inhalt prüfen: cd /var/www, danach ls -l, um zu sehen, was dort bereits liegt.
  • Konfigurationsdatei sichern: cp nginx.conf nginx.conf.bak, bevor Änderungen vorgenommen werden.
  • Externe Backup-Platte einhängen: mount /dev/sdb1 /mnt/backup, danach mit ls -l /mnt/backup den Inhalt prüfen.
  • Dauerhaftes Einhängen: Eintrag der Backup-Platte in /etc/fstab, damit sie bei jedem Neustart automatisch verfügbar ist.
  • Fehlersuche: cat /var/log/nginx/error.log | grep "error" filtert gezielt Fehlermeldungen aus einer langen Logdatei, statt sie komplett mit cat allein auszugeben.

Merksatz

Navigation: pwd, cd, ls. Dateioperationen: cp, mv, rm, mkdir. Inhalt ansehen/durchsuchen: cat, less, grep, per Pipe (|) verkettet. Linux hat einen Verzeichnisbaum statt Laufwerksbuchstaben, Datenträger werden gemountet, /etc/fstab steuert das automatische Einhängen beim Boot. man befehl zeigt die Dokumentation eines Befehls.
