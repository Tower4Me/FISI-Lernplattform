Verschachtelung & Kaskadierung von Kontrollstrukturen AP1

Einstieg

Verschachtelung ist wie eine Matrjoschka-Puppe: eine komplette Kontrollstruktur steckt vollständig innerhalb einer anderen. Kaskadierung dagegen ist wie eine Reihe von Kontrollstationen am Flughafen, die hintereinander auf derselben Ebene durchlaufen werden — jede Station wird nur erreicht, wenn die vorherige nicht schon zum Ausschluss geführt hat.

Konzept

Verschachtelung (Nesting)

Bei einer Verschachtelung steckt eine komplette Kontrollstruktur (Verzweigung oder Schleife) im Körper einer anderen. Die Einrückungstiefe nimmt dabei mit jeder Ebene zu. Typische Fälle: eine Schleife in einer Schleife (z. B. für Tabellen/Matrizen — äußere Schleife läuft über Zeilen, innere über Spalten) oder eine Verzweigung im Körper einer Schleife:

FÜR JEDE Zeile IN Tabelle TUE FÜR JEDE Spalte IN Zeile TUE AUSGABE Spalte ENDE FÜR ENDE FÜR

Kaskadierung

Bei einer Kaskadierung stehen mehrere Bedingungen nacheinander auf derselben Ebene, meist als Kette aus SONST WENN. Die Einrückungstiefe bleibt gleich, es entsteht keine „Struktur in der Struktur“, sondern eine Kette von Alternativen:

WENN Menge >= 500 DANN Rabatt = 20% SONST WENN Menge >= 100 DANN Rabatt = 10% SONST Rabatt = 0% ENDE WENN

Praxisbeispiel

Die TechNord GmbH berechnet für jede Bestellung einer Kundenliste den Rabatt jeder einzelnen Position:

FÜR JEDE Bestellung IN Kundenliste TUE FÜR JEDE Position IN Bestellung.Positionen TUE WENN Position.Menge >= 500 DANN Position.Rabatt = 20% SONST WENN Position.Menge >= 100 DANN Position.Rabatt = 10% SONST Position.Rabatt = 0% ENDE WENN ENDE FÜR ENDE FÜR

Die beiden FÜR JEDE-Schleifen sind verschachtelt: die innere Schleife (Positionen) steckt vollständig im Körper der äußeren Schleife (Bestellungen). Die WENN-Kette innerhalb der inneren Schleife ist dagegen kaskadiert: Menge >= 500, dann Menge >= 100, dann der SONST-Fall — drei Alternativen auf derselben Ebene, keine steckt in der anderen.

Übungsaufgabe

Schreibe eine verschachtelte Zählschleife in Pseudocode, die eine kleine Einmaleins-Tabelle ausgibt (1 bis 3 mal 1 bis 3).

Musterlösung anzeigen 
FÜR i VON 1 BIS 3 TUE
  FÜR j VON 1 BIS 3 TUE
    AUSGABE i * j
  ENDE FÜR
ENDE FÜR

Die äußere Schleife läuft über i, die innere über j. Die innere Schleife steckt vollständig im Körper der äußeren — das ist die Verschachtelung: für jeden Wert von i läuft die innere Schleife komplett von 1 bis 3 durch.

Merksatz

Verschachtelung: eine Kontrollstruktur steckt vollständig im Körper einer anderen, die Einrückungstiefe steigt (z. B. Schleife in Schleife). Kaskadierung: mehrere Bedingungen stehen als SONST-WENN-Kette hintereinander auf derselben Ebene, die Einrückungstiefe bleibt gleich. Beides kann in derselben Struktur gleichzeitig vorkommen.
