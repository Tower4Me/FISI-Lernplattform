Die Tierarztpraxis hat Daten in vielen Formen: eine Tabelle, PDF-Befunde, Röntgenbilder, eine Exportdatei des Labors. Ob du eine Datei mit jedem Editor öffnen und weiterverarbeiten kannst oder ein bestimmtes Programm brauchst, hängt davon ab, ob sie als Text oder binär gespeichert ist.

Zwei Grundformen

TextdateiBinärdatei
Inhaltnur Zeichen in einer Zeichenkodierung (deshalb auch „ASCII-Datei“ genannt), etwa ASCII oder UTF-8 (Kapitel 5.1.3)beliebige Bytes nach einem festgelegten Format
Öffnenmit jedem Texteditor lesbar und bearbeitbar, wenn die Zeichenkodierung stimmtnur mit einem Programm, das das Format kennt; im Editor erscheint Zeichensalat
Größeoft größer, Zahlen stehen als Ziffernfolgenoft kompakter, Zahlen stehen direkt als Bytes
Beispiele.txt, .csv, .json, .xml, .html, Quellcode.png, .jpg, .pdf, .exe, .docx, .xlsx, Datenbankdateien

Auch eine Zahl kann so oder so gespeichert sein: Als Text braucht 1250 vier Zeichen, also 4 Byte in ASCII. Binär als 16-Bit-Ganzzahl braucht sie 2 Byte. Dafür ist die Textform für Menschen lesbar und von jedem Programm verarbeitbar.

Moderne Office-Dateien wie .docx sind übrigens ZIP-Archive mit XML-Dateien darin: Der Inhalt ist größtenteils Text (Bilder liegen binär darin), die Datei als Ganzes ist binär. Deshalb beginnt sie wie jedes ZIP-Archiv mit den Zeichen PK.

Woran du ein Format erkennst

  • Dateiendung: ein Hinweis, aber leicht änderbar und nicht verbindlich.
  • Dateisignatur: Viele Binärformate beginnen mit festen Bytes, etwa PDF mit %PDF, PNG mit den Bytes 89 50 4E 47 (hexadezimal, Kapitel 5.1.2). Programme erkennen das Format daran auch bei falscher Endung.
  • MIME-Typ: Im Web und bei E-Mail-Anhängen gibt eine Angabe wie application/pdf oder text/csv das Format an.
  • Base64: Wo nur Text übertragen werden darf, etwa im E-Mail-Anhang, wird eine Binärdatei in Textzeichen umkodiert. Sie wird dadurch rund ein Drittel größer.

Formate umwandeln

Passt das Format der Quelle nicht zum Zielprogramm, gibt es mehrere Wege: die Exportfunktion der Quelle (etwa „Speichern unter CSV“), die Importfunktion des Ziels, einen Dateikonverter oder ein kleines eigenes Umwandlungsprogramm. Prüfe danach stichprobenartig, ob Umlaute, Datumsangaben und Kommazahlen richtig angekommen sind.

Beispiel

Das Laborgerät der Praxis speichert Messreihen in einem herstellereigenen Binärformat. Die neue Praxissoftware liest aber nur CSV. Der Auszubildende findet in der Gerätesoftware eine Exportfunktion „Messwerte als CSV“, richtet sie als tägliche Aufgabe ein und prüft, dass Dezimalzahlen wie 38,5 nicht als 385 ankommen.

„Ich benenne die Datei von .xlsx in .csv um, dann ist sie CSV.“ Nein: Die Endung ändert nicht den Inhalt. Die Datei bleibt ein Excel-Format; umwandeln muss sie ein Programm per Export.

  • Textdatei: nur Zeichen in einer Kodierung, mit jedem Editor lesbar; Binärdatei: beliebige Bytes, braucht ein passendes Programm, oft kompakter.
  • Format erkennen an Endung, Dateisignatur und MIME-Typ; umwandeln per Export, Import oder Konverter, danach Stichprobe.
