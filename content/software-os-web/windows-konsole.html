Einstieg

Genau wie die Linux-Konsole ist die Windows-Eingabeaufforderung (cmd.exe) ein Gespräch mit dem Betriebssystem in kompakten Befehlswörtern — nur mit anderem Wortschatz. Wer dir statt ls und copy statt cp kennt, kommt unter Windows genauso schnell ohne Maus und Menüs ans Ziel.

Konzept

Navigation

BefehlZweck
cdzeigt das aktuelle Verzeichnis an bzw. wechselt hinein; cd .. eine Ebene nach oben
dirlistet den Verzeichnisinhalt auf — das Windows-Pendant zu Linux ls

Dateioperationen

BefehlZweck
copy quelle zielkopiert eine Datei
move quelle zielverschiebt oder benennt eine Datei um
del dateilöscht eine Datei
mkdir ordnerlegt ein neues Verzeichnis an

Dateiinhalt ansehen und Hilfe

BefehlZweck
type dateigibt den Dateiinhalt aus — das Windows-Pendant zu Linux cat
befehl /?zeigt die verfügbaren Optionen eines Befehls an

Netzwerkdiagnose

BefehlZweck
ipconfig / ipconfig /allzeigt die Netzwerkkonfiguration (IP-Adresse, Subnetzmaske, Gateway) an — siehe auch Modul Netzwerktechnik, Netzwerk-Diagnose
getmaczeigt die MAC-Adresse(n) der Netzwerkadapter an, z. B. für eine DHCP-Reservierung

PowerShell als modernes Pendant

Neben der klassischen Eingabeaufforderung (cmd.exe) bietet Windows mit PowerShell eine moderne, deutlich mächtigere Konsole mit eigener Skriptsprache (siehe Einheit „Windows vs. Linux/Unix & Domäne“) — für einfache Datei- und Netzwerkbefehle wie oben reicht aber weiterhin die klassische Eingabeaufforderung.

Praxisbeispiel

Ein Techniker der TechNord GmbH richtet einen neuen Windows- Arbeitsplatz ein:

  • Konfigurationsordner prüfen: cd C:\Programme\TechNordTool, danach dir, um den Inhalt zu sehen.
  • Vorlage kopieren: copy vorlage.cfg einstellungen.cfg, um eine Konfigurationsvorlage als Ausgangspunkt zu übernehmen.
  • Datei inhaltlich prüfen: type einstellungen.cfg, um die Einträge vor dem Deployment zu kontrollieren.
  • Netzwerkdiagnose: ipconfig /all zeigt die aktuelle IP-Konfiguration, getmac liefert die MAC-Adresse für eine feste DHCP-Reservierung.

Merksatz

Navigation: cd, dir (Pendant zu Linux ls). Dateioperationen: copy, move, del, mkdir. type zeigt Dateiinhalt an (Pendant zu Linux cat), befehl /? zeigt Hilfe. ipconfig zeigt die Netzwerkkonfiguration, getmac die MAC-Adresse. PowerShell ist die modernere, mächtigere Alternative zur klassischen Eingabeaufforderung.
