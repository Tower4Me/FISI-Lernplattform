Einstieg

Ein Firmengebäude hat oft einen Empfangsbereich, den auch externe Besucher betreten dürfen, ohne gleich Zutritt zu den Büros im Inneren zu bekommen. Zwischen Empfang und Büros liegt eine weitere verschlossene Tür. Selbst wenn im Empfangsbereich etwas schiefgeht, bleibt der eigentliche Kernbereich geschützt. Genauso funktioniert eine Firewall mit einer DMZ im Netzwerk. Ohne eine solche Zwischenzone hinge zwischen Internet und internem Netz nur eine einzige Grenze: Wäre der öffentlich erreichbare Server (z. B. Webshop) einmal geknackt, stünde der Angreifer damit sofort mitten im internen Netz mit Fileservern und Kundendaten.

Konzept

Welche Funktionen eine einzelne Firewall hat (Paketfilter, SPI, ALG, NGFW), behandelt die Einheit Firewall-Funktionen. Hier geht es darum, wie Firewalls im Netz angeordnet werden.

Die DMZ

Eine DMZ (Demilitarisierte Zone) ist ein Puffernetz zwischen Internet und internem LAN. Server, die von außen erreichbar sein müssen (Webserver, Mailserver), stehen hier. Wird ein DMZ-Server gehackt, hat der Angreifer noch keinen Zugriff auf das interne Netz – dazwischen liegt eine zweite Firewall-Grenze.

Firewall-Architekturen im Vergleich

ArchitekturAufbauStärkeSchwäche
Einstufig Eine Firewall zwischen Internet und LAN; eine DMZ hängt, falls vorhanden, an einer dritten Schnittstelle derselben Firewall Günstig, einfach zu verwalten Single Point of Failure: Ein Fehler oder eine Lücke in diesem einen Gerät öffnet alle Zonen
Zweistufig Zwei Firewalls hintereinander, die DMZ liegt dazwischen Ein Angreifer muss zwei getrennte Grenzen überwinden Mehr Geräte, mehr Regelwerke, höherer Aufwand
Screened Subnet Eigenes Subnetz (die DMZ) zwischen äußerem und innerem Paketfilter; die öffentlich erreichbaren Server stehen nur in diesem Subnetz Klare Trennung: Das LAN ist von außen gar nicht direkt adressierbar Schutz hängt an den Regeln zweier Paketfilter, kein Blick in Anwendungsinhalte
P-A-P Paketfilter – Application Level Gateway – Paketfilter; der gesamte Verkehr muss durch das ALG in der Mitte Höchste Schutzstufe: keine direkte Verbindung, Kontrolle bis Schicht 7 Teuer, aufwendig, jedes Protokoll braucht einen passenden Proxy im ALG

Screened Subnet ist der klassische Fachbegriff für die zweistufige DMZ-Bauweise mit zwei Paketfiltern („screening router“). Setzt man in die Mitte zusätzlich ein Application Level Gateway, entsteht die P-A-P-Struktur. Bei einer zweistufigen Lösung werden oft Firewalls von zwei verschiedenen Herstellern eingesetzt: Eine Sicherheitslücke in einem Produkt öffnet dann nicht gleich beide Grenzen.

Reverse-Proxy in der DMZ

Ein Reverse-Proxy sitzt in der Praxis häufig in der DMZ: Er nimmt Anfragen aus dem Internet entgegen und leitet sie gezielt an die eigentlichen Backend-Server im internen Netz weiter, ohne deren Adressen oder Struktur nach außen preiszugeben.

Praxisbeispiel

Die „Baumann IT-Systemhaus GmbH“ plant das Netzwerk für einen Kunden mit eigenem Webshop und internem Fileserver:

  • Der Webshop-Server muss von jedem Kunden im Internet erreichbar sein → er kommt in die DMZ, nicht ins interne LAN.
  • Firewall 1 (zwischen Internet und DMZ) lässt nur HTTPS-Verkehr (Port 443) zum Webshop-Server durch.
  • Firewall 2 (zwischen DMZ und internem LAN) lässt nur die eine Verbindung durch, die der Webshop-Server für Bestelldaten zur internen Datenbank benötigt – sonst nichts.
  • Ein Angreifer, der eine Schwachstelle im Webshop ausnutzt, landet damit nur in der DMZ. Um an den internen Fileserver mit den Kundendaten zu gelangen, müsste er zusätzlich Firewall 2 überwinden.
  • Eine einstufige Lösung mit einer einzigen Firewall und DMZ-Schnittstelle wäre günstiger. Weil aber Kundendaten betroffen sind, empfiehlt Baumann die zweistufige Variante mit Geräten zweier Hersteller.

Merksatz

Die DMZ ist ein Puffernetz zwischen zwei Firewalls für von außen erreichbare Server – ein kompromittierter DMZ-Server öffnet nicht automatisch das interne LAN. Einstufig = ein Gerät (Single Point of Failure), zweistufig/Screened Subnet = zwei Grenzen, P-A-P = Paketfilter – Application Level Gateway – Paketfilter.
